# 루베의 밤

친구 루베를 위한 수면 소리 앱입니다.  
유튜브 화면 없이, 설정한 영상의 소리만 흘려 줍니다.

**웹에서 열기:** [gamepple.github.io/Rube-night](https://gamepple.github.io/Rube-night/)

## 쓰는 법

1. 가운데 전원 버튼을 켜면 별과 달이 빛나고, 소리가 시작됩니다.
2. 다시 누르면 일시정지되고, 아래에 **종료하기**가 나옵니다.
3. 종료하면 요일, 날씨, 잠든 시간, 짧은 인사와 문장이 나옵니다.
4. 오른쪽 위 설정에서 유튜브 주소를 여러 개 넣을 수 있고, **순차** 또는 **랜덤**으로 이어집니다.
5. 영상이 끝나면 다음 소리가 자동으로 이어지고, 하나만 있으면 처음부터 다시 반복됩니다.

기본 영상은 [루베가 듣는 ASMR](https://youtu.be/-u98Ob6R8AU)입니다.

## GitHub Pages

이 저장소는 GitHub Pages로 배포됩니다.

- 주소: `https://gamepple.github.io/Rube-night/`
- 소스: `main` 브랜치 루트의 `index.html`
- 코드를 고친 뒤 `main`에 올리면 잠시 후 사이트에 반영됩니다.

Pages가 꺼져 있다면 저장소에서 **Settings → Pages → Build and deployment**로 가서 Source를 **Deploy from a branch**, Branch를 **main**, Folder를 **/** (root)로 두면 됩니다.
