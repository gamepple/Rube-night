# 루베의 밤

유튜브 추천 영상 없이, 정해 둔 영상의 **소리만** 들으며 잠드는 수면 앱입니다.

친구 루베가 밤에 잠을 잘 못 이뤘 긴 ASMR을 틀어 두는데, 유튜브를 열면 다른 영상이 보여 잠이 깨는 문제를 위해 만들었습니다.

## 쓰는 법

1. 가운데 전원 버튼을 켜습니다. 버튼에서 엽은 빛이 나고, 영상의 소리만 흘러요.
2. 흘러간 시간이 표시됩니다.
3. 버튼을 한 번 더 누르면 일시정지되고, 아래의 **종료하기**가 나타납니다.
4. 종료하면 오늘의 요일, 날씨, 짧은 글과 함께 좋은 하루를 건넥니다.

기본 영상은 [5시간 지하철 ASMR](https://youtu.be/-u98Ob6R8AU)입니다. 오른쪽 위 설정에서 다른 유튜브 링크로 바꿀 수 있습니다.
